# 💬 Simple Chat Application (WhatsApp Web Clone)

A simple browser-based chat application built using **HTML, CSS, and JavaScript**.  
This project mimics the basic interface and functionality of WhatsApp Web, allowing users to send messages, switch users, and store chat data locally using **LocalStorage**.

---

## 📌 Project Overview

This project is a **frontend chat application** designed to demonstrate:

- DOM manipulation
- LocalStorage usage
- Dynamic UI updates
- Simple message handling
- User switching functionality

All chat data is stored locally in the browser, so no backend server is required.

---

## ✨ Features

### 👤 User Features
- Create new users
- Switch between existing users
- View profile information

### 💬 Messaging Features
- Send messages
- Delete messages
- View chat history
- Messages display with timestamps

### 📂 Data Persistence
- Messages are saved in **LocalStorage**
- Users remain saved even after refreshing the page

### 🎨 Interface Features
- Clean WhatsApp-like UI
- Contact list sidebar
- Chat message bubbles
- Responsive layout
- Simple navigation

---

## 🖥️ Application UI

The interface contains three main sections:

### 1️⃣ Left Sidebar

### 2️⃣ Chat Header

### 3️⃣ Chat Area

- Sent message bubbles
